# csvreader

CSVおよびExcelファイルを閲覧するためのシンプルなブラウザベースのツールです。ファイルをドラッグ＆ドロップするだけで、すぐにデータを確認できます。

## デモ

https://code4fukui.github.io/csvreader/

## 機能

-   **幅広いファイル対応**: CSVおよびExcelファイル（`.xls`、`.xlsx`）を読み込めます。
-   **複数ファイルの閲覧**: 複数のファイルを一度にドラッグ＆ドロップして、合わせたデータを表示できます。
-   **リアルタイムフィルタリング**: フィルターボックスを使って、すべてのレコードを即座に検索できます。スペース区切りによる複数キーワード検索に対応しています。
-   **インストール不要**: Webブラウザ上で完全に動作します。セットアップやソフトウェアのインストールは必要ありません。

## 要件

モダンなWebブラウザ。

## 使い方

1.  [デモページ](https://code4fukui.github.io/csvreader/)を開きます。
2.  1つ以上のCSVまたはExcelファイルをページにドラッグ＆ドロップします。
3.  ファイルの内容がレコードのリストとして表示されます。
4.  上部のフィルター入力欄を使用して、データをリアルタイムに検索します。
