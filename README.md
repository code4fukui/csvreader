# csvreader

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple, browser-based tool to view CSV and Excel files. Just drag and drop your files to instantly see the data.

## Demo

https://code4fukui.github.io/csvreader/

## Features

-   **Broad File Support**: Reads CSV and Excel files (`.xls`, `.xlsx`).
-   **Multi-File Viewing**: Drag and drop multiple files at once to view their combined data.
-   **Real-time Filtering**: Instantly search through all records using a filter box. Supports multiple space-separated keywords.
-   **Zero Installation**: Runs entirely in your web browser. No setup or software installation is needed.

## Requirements

A modern web browser.

## Usage

1.  Open the [demo page](https://code4fukui.github.io/csvreader/).
2.  Drag and drop one or more CSV or Excel files onto the page.
3.  The file contents will be displayed as a list of records.
4.  Use the filter input at the top to search through the data in real-time.
